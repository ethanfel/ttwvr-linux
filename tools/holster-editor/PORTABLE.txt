TTWVR HOLSTER EDITOR — FIELD KIT 1.6.4

1. Extract this ZIP to a folder.
2. Open TTWVR-Holster-Editor.html in a current browser (Edge, Chrome or Firefox).
3. Load your TTWVR.state file. Select a numbered holster, then choose a body
   anchor from the diagram or list. Drag its numbered centre to position it.
   Choose Seated · desk chair under Pose to check reach around the seat and
   armrests. It works in Front, Side and 3D. Pose changes affect the preview only.
   Body outline shows the skin estimate in every view. Red hatching marks the
   part of a grab sphere inside that estimate. Adjust Estimated body
   weight (45–180 kg) to check pouch clearance. The original reference is 75 kg.
   In 3D, drag the background to orbit and scroll to zoom. Drag R (right),
   F (forward) or U (up) to move the selected holster or pouch along one axis.
   Switch Front/Side to adjust all three dimensions. Drag the square handle on
   the circle to resize the grab sphere. Values and the grid are in centimetres.
   Arrow keys move 1 cm; Shift + arrows moves 5 cm. Escape cancels a drag.
   Mirror to another slot copies this placement to the opposite body side.
   The destination is replaced; Undo restores it. Later edits remain independent.
   For the ammo pouch, select Ammo pouch and drag P in Front and Side.
   Choose a torso anchor or Body-relative. Set Grab radius to 5–45 cm,
   or select Use game radius to inherit the VR setting.
   If you have never placed it, choose Set initial position first.
4. Export a copy. With the game and mod manager closed, back up the original
   TTWVR.state and replace it with the exported file. Remove any browser-added
   suffix such as "(1)". Launch the game and check the placement in VR.

Windows location, inside your Documents folder (possibly redirected to OneDrive):
  My Games\FalloutNV\TTWVR.state

Linux/Proton location, inside the prefix used by your VR profile:
  drive_c/users/steamuser/Documents/My Games/FalloutNV/TTWVR.state

Editing holsters needs SavedSlots and SavedSlotsOn sections. If these do not exist,
place/toggle a holster in VR and quit once so TTWVR saves the full configuration.

The editor runs offline on Windows and Linux. No Python, Node, installation,
account or server is needed. It does not upload anything or overwrite game files.
Try a sample demonstrates the controls; load your own file before exporting.

Holsters: TTWVR 1.1.5–1.1.7. Ammo pouch: TTWVR 1.1.7. Eight game hotkey slots, ten explicit bone
anchors, automatic anchoring, local offsets, enabled flags, visibility and grab
radius. The preview shows offsets and radius on an approximate reference body,
not your live avatar. Final fit depends on calibration and pose. Automatic
markers show their saved eye-relative positions and can be dragged in either view.
Changing an anchor preserves its local offsets. New bindings start at zero.
Automatic removes the explicit binding: the game chooses a nearby bone using
its saved body-relative position when the avatar is ready.

Other state sections, including calibration and Pip-Boy settings, are retained.
This tool does not assign inventory items or fix holster drift.

Recovery for an old Field Kit 1.1 tab with unsaved edits:
If export reports "Export verification failed for a position value", keep the
old tab open. In that editor tab, open the browser console (Chrome/Edge on
Linux or Windows: Ctrl+Shift+J), paste the contents of Recover-Open-Tab.js and
press Enter. This repairs export in memory and downloads the current state.
Once saved, open the updated editor and load that downloaded file.
The repair only changes the open editor; it does not install the state in-game.

PRESET LAYOUTS
Open Preset layouts above the slot list to compare seven gear-style profiles:
Wasteland rig (8), Gun belt (4), Chest rig (6), Travel vest (6),
Shoulder rig (6), Field rig (8), and Utility rig (8).
The default has four belt positions and four chest/abdomen pockets. The belt
wraps around the waist, with front pouches and side hip holsters. There are no
double targets on the arms. Utility rig adds one forearm target opposite the
selected Pip-Boy arm: right reserved, left forearm available by default.
Each profile includes one ammo pouch marked P in both previews. Select its
left or right side before applying. Export saves its position, anchor and radius.
Choose paired slot order and optional 5 or 10 cm extra forward reach, preview,
then Apply. Pip-Boy arm reserves that arm; it does not move the in-game Pip-Boy.
One Undo restores the previous layout. Unused slots are disabled while their
placements are retained. Calibration, visibility and other state stay unchanged.
Profiles are starting points: check comfort and reach in VR. Export each edited
layout to keep it as a separate profile.

BODY HOLSTERS BEHIND YOU — FRONT/BACK FIX IN FIELD KIT 1.4
Field Kit 1.1–1.3 incorrectly showed front and back reversed. Open your state
in this updated version, then Help > Repair old body placement to move body
centres from behind to in front of the reference body. Pelvis, chest, thigh and
shin slots are included, even disabled ones. Arms and Automatic are unchanged.
Intentional rear body holsters would also move. Review the Side view; Undo
restores the layout. Loading never auto-repairs. Export and replace the state
with the game closed, keeping a backup. A fresh preset also uses the fixed axes.
