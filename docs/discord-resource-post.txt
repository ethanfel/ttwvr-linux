----- MESSAGE 1 -----
**TTWVR on Linux: original renderer + DLSS / FSR**

This project patches a prepared Tale of Two Realities / TTWVR installation for **native Fluorine + Proton + WiVRn**.

The focus is the original mod's VR menu, controls and renderer:
• Author's bundled Vulkan/DXVK renderer.
• DLSS through the author's 64-bit **D3D11 NGX helper**, with repaired shared output and GPU synchronization.
• Native **Vulkan FSR 3.1.4** in the 32-bit game.
• Original resolution, upscaler-level and sharpness controls.

DLSS is not a new direct Vulkan NGX implementation. Our previous custom D3D12 NR/DLAA/SR/FG addon is archived and is not needed for this setup.

**Repository:** <https://github.com/ethanfel/ttwvr-linux>
**Start here:** <https://github.com/ethanfel/ttwvr-linux/blob/main/docs/installation.md>

You supply the games, TTW, utilities and original TTWVR files. The Linux tool creates a separate patched mod, private compatibility files, a launcher and rollback records. No game/mod/NVIDIA DLLs are bundled.

----- MESSAGE 2 -----
**1. Prepare your install**

• Own English New Vegas Ultimate and Fallout 3 GOTY with all DLC.
• Install TTW and all required utilities/presets. Use FNV4GB **for Proton**.
• Prepare native **Fluorine 0.4.1**, its TTW plugin, **FUSE**, a dedicated game copy and initialized private Proton prefix.
• Make **TTW - Flat** work first: Utilities Checker passes, intro works, save/reload works. Keep that profile and its saves.
• Duplicate it as **TTW - VR**. Install and enable the complete original **TTWVR 1.1.4 or 1.1.3** archive as a separate mod.
• Set up WiVRn and xrizer. Use regular mod files or reflinks: the tested Fluorine skips symlinked BSA assets.

**TTW guide:** <https://thebestoftimes.moddinglinked.com/intro.html>
**Native TTW installer:** <https://github.com/SulfurNitride/TTW_Linux_Installer>
**Fluorine:** <https://github.com/SulfurNitride/Fluorine-Manager/releases/tag/v0.4.1>
**TTWVR download:** <https://discord.com/channels/747967102895390741/1560413111423344730>

The exact tested Proton build is **experimental-11.0-20261105c-x86_64**, with Steam Linux Runtime 4. Newer Experimental builds are not automatically compatible; the tool checks hashes and stops on unknown versions.

Install Python 3.11+, Git, bubblewrap, FUSE 3, unshare, Meson, Ninja, glslang and i686 MinGW-w64 C/C++ with POSIX threads. See the full guide for paths and prerequisites.

----- MESSAGE 3 -----
**2. Apply the Linux patch**

Clone the repository, copy its setup template, and edit the paths to your prepared install:
```sh
git clone https://github.com/ethanfel/ttwvr-linux.git
cd ttwvr-linux
cp tools/setup.example.json setup.json
python3 tools/setup_linux.py check setup.json
```

Run as your desktop user. Close Fallout and Fluorine, then:
```sh
python3 tools/setup_linux.py apply setup.json
```

The first run prepares checksum-pinned shader compilers and builds the patched DXVK dependency. It keeps the original mod and settings, creates a Linux-patched copy, configures Fluorine and prints your launch command.

**3. Connect WiVRn and launch**
```sh
python3 "/your/linux-fixes/launch-ttwvr.py"
```
Use the exact path printed by the tool. For Steam, copy **linux-fixes/steam-launch-options.txt** into New Vegas's Launch Options. Fluorine mounts the mods and starts the game automatically.

Choose DLSS or FSR in the original **VR Settings**. Existing resolution, sharpness and calibration settings are preserved. The tool does not force 200% or a fixed FPS target.

To prepare downloads/builds separately, use `python3 tools/setup_linux.py prepare setup.json` before apply. The checked cache is reused.

**Full instructions:** <https://github.com/ethanfel/ttwvr-linux/blob/main/docs/installation.md>

**Troubleshooting:** <https://github.com/ethanfel/ttwvr-linux/blob/main/docs/troubleshooting.md>

Close Fallout and Fluorine before rollback:
```sh
python3 tools/setup_linux.py rollback "/your/linux-fixes/transaction.json"
```
It restores original configuration/compiler files and mod selection. Saves are untouched; private build/mod copies are retained. Restore your previous Steam launch option separately. Rollback stops if later edits would be overwritten; the guide explains the backed-up `--force` option.
