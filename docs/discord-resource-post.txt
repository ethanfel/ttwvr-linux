----- MESSAGE 1 -----
**Play Tale of Two Wastelands in VR on Linux**

This guide sets up **Tale of Two Realities / TTWVR** with **native Fluorine, Proton and WiVRn**, including **DLSS and FSR** and the mod's VR settings and controls.

The workflow is:
**Prepare a working TTW installation → run the Linux patch tool → connect WiVRn and play.**

The tool checks compatibility, prepares the Linux dependencies, creates a patched copy of TTWVR and configures the launcher. It preserves your settings and saves, keeps the original mod, and records backups for rollback.

**Full installation guide:** <https://github.com/ethanfel/ttwvr-linux/blob/main/docs/installation.md>
**Repository:** <https://github.com/ethanfel/ttwvr-linux>
**Linux patch code license:** GPL-3.0-only; third-party licenses remain unchanged.

You need your own games and mod downloads. The tool does not install TTW or download Nexus mods; no game, TTWVR or NVIDIA runtime files are bundled.

----- MESSAGE 2 -----
**1. Prepare your installation**

• English **Fallout: New Vegas Ultimate** and **Fallout 3 GOTY**, with all DLC.
• TTW and all required utilities and INI presets from **The Best of Times**. Apply **FNV4GB for Proton**.
• **Fluorine 0.4.1**, using its TTW game plugin and **FUSE** backend, with a dedicated game copy and initialized private Proton prefix.
• A working **TTW - Flat** profile: Utilities Checker passes, the intro runs, and you can save and reload.
• A **TTW - VR** copy of that profile, with the complete original **TTWVR 1.1.4** archive installed and enabled as a separate mod.
• Working **WiVRn and xrizer**. DLSS requires a supported NVIDIA RTX GPU.

**Proton:** get `proton-cachyos-wineopenxr-fix.tar.gz` (`cachyos-11.0-20261015-slr`) from <https://discord.com/channels/1570233209462194208/1570481280825561098> and use **Steam Linux Runtime 4**. Extract the full archive and select it in Fluorine. The tool combines its OpenXR fix with our Linux patches. Exact `experimental-11.0-20261105c-x86_64` also remains supported; newer builds need validation.

Linux prerequisites: Python 3.11+, Git, bubblewrap, FUSE 3, unshare, Meson, Ninja, glslang and i686 MinGW-w64 C/C++ with POSIX threads. The full guide explains the paths and setup.

**TTW guide:** <https://thebestoftimes.moddinglinked.com/intro.html>

Use regular files or reflinks for mod assets. The tested Fluorine version skips symlinked assets, which can cause missing files and crashes.

----- MESSAGE 3 -----
**2. Apply the Linux patch**

Download the tool and copy its setup template:
```sh
git clone https://github.com/ethanfel/ttwvr-linux.git
cd ttwvr-linux
cp tools/setup.example.json setup.json
```

Open **setup.json** and replace the example paths with your own. Point `mod` to the installed TTWVR mod directory. Choose a new, separate directory for `fixes`; it will hold dependencies, backups and the launcher.

Check your preparation:
```sh
python3 tools/setup_linux.py check setup.json
```

Resolve any reported errors. **Close Fallout and Fluorine**, then apply as your normal desktop user:
```sh
python3 tools/setup_linux.py apply setup.json
```

The first run downloads the required shader compilers and builds the patched DXVK dependency. Allow several GB of free space and let the build finish. The tool then configures your VR profile and prints the launch and rollback commands.

**3. Connect your headset in WiVRn and play**

Run the exact launch command printed by the tool. It looks like:
```sh
python3 "/your/linux-fixes/launch-ttwvr.py"
```

For Steam, copy **linux-fixes/steam-launch-options.txt** into **New Vegas → Properties → Launch Options**. Fluorine mounts the mods and starts the game automatically.

Use **VR Settings** to choose DLSS or FSR, upscaler level, resolution and sharpness. Your existing calibration and settings are preserved.

----- MESSAGE 4 -----
**Help and rollback**

• Connect WiVRn before launching the game.
• Use the generated launcher so the required Linux fixes are applied.
• If a file-version check fails, follow the guide's supported versions; do not bypass it.
• To open Fluorine without starting Fallout, add `--manager-only` to the generated launch command.
• For flat play, close Fallout and Fluorine, then add `--profile "TTW - Flat"`. Keep TTWVR disabled in that profile.

**Troubleshooting:** <https://github.com/ethanfel/ttwvr-linux/blob/main/docs/troubleshooting.md>
**Tested hardware, validation and compatibility:** <https://github.com/ethanfel/ttwvr-linux/blob/main/docs/compatibility.md>

To undo the patch, close Fallout and Fluorine and run:
```sh
python3 tools/setup_linux.py rollback "/your/linux-fixes/transaction.json"
```

Rollback restores the backed-up configuration, compiler files and mod selection. Saves are untouched. Private build files and the patched mod copy are retained. Restore your previous Steam launch option separately.

If settings have changed since installation, rollback stops to protect those edits. The full guide explains how to preserve them and restore the backups.
