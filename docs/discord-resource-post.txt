----- MESSAGE 1 -----
**TTWVR on Linux — start here**

Play **Tale of Two Wastelands in VR** with **Tale of Two Realities / TTWVR**, native **Fluorine**, **Proton** and **WiVRn**, including the mod's **DLSS, FSR and VR settings**.

**New installation?** Follow the preparation guide. It shows the folders, conversion steps, Fluorine settings and first game test:
<https://github.com/ethanfel/ttwvr-linux/blob/main/docs/preparation.md>

**TTW already works in native Fluorine?** Go straight to the Linux patch guide:
<https://github.com/ethanfel/ttwvr-linux/blob/main/docs/installation.md>

**Downloads and required packages:**
<https://github.com/ethanfel/ttwvr-linux/blob/main/docs/requirements.md>

**TTWVR community:** <https://discord.com/invite/ttwvr>

You need your own games and mod downloads. The patch tool prepares the Linux dependencies and launcher; it does not install TTW or download Nexus mods.

----- MESSAGE 2 -----
**Before applying the patch**

Check these in order:

1. Native **Fluorine 0.4.1** uses the **TTW** game plugin and **FUSE**.
2. **TTW - Flat** starts with all required utilities. The checker says **All utilities installed!**, and a save reloads.
3. **TTW - VR** is a copy of that profile with one complete original **TTWVR 1.1.5** mod enabled. The exact supplied 1.1.4 and 1.1.3 builds are also supported.
4. Fluorine uses a private prefix and a supported Proton build.
5. WiVRn connects to your headset. xrizer and the Linux build prerequisites are installed.

**Proton download:** `proton-cachyos-wineopenxr-fix.tar.gz` from:
<https://discord.com/channels/1570233209462194208/1570481280825561098>

Extract the whole archive. The tested version is `cachyos-11.0-20261015-slr`; use **Steam Linux Runtime 4** with it. The tool combines this OpenXR fix with the TTWVR/DXVK patches.

Exact `experimental-11.0-20261105c-x86_64` is also supported. Other releases need validation; do not mix files between Proton builds.

The preparation guide has the download links and exact settings for each step.

----- MESSAGE 3 -----
**Apply the Linux patch**

**1. Get the tool**
```sh
git clone https://github.com/ethanfel/ttwvr-linux.git
cd ttwvr-linux
cp tools/setup.example.json setup.json
```
If you cloned it during preparation, just enter that repository and copy the template.

**2. Edit setup.json — three paths**
```json
{
  "workspace": "~/Games/ttwvr",
  "manager": "apps/fluorine-manager/fluorine-manager",
  "steam_library": "~/.local/share/Steam"
}
```
• `workspace`: your TTWVR folder containing instance, config and share.
• `manager`: the Fluorine executable, relative to workspace or an absolute path.
• `steam_library`: the folder above steamapps that contains SteamLinuxRuntime_4.

Proton, prefix and the enabled TTWVR mod are read from Fluorine. Patch output goes to **workspace/linux-fixes**. No repeated paths needed.

Different layout? Add only the overrides you need:
<https://github.com/ethanfel/ttwvr-linux/blob/main/docs/configuration.md>

**3. Check**
```sh
python3 tools/setup_linux.py check setup.json
```
Continue when it prints **Preflight passed**. Correct any reported error first.

**4. Close Fallout and Fluorine, then apply**
```sh
python3 tools/setup_linux.py apply setup.json
```
Run as your normal user, without sudo. The first run downloads compilers and builds the renderer; leave the terminal open until launch commands appear.

Original mods, saves and settings are retained. The tool creates a separate patched mod and rollback backups.

----- MESSAGE 4 -----
**Launch from Steam**

1. Connect the headset in **WiVRn**.
2. Open **workspace/linux-fixes/steam-launch-options.txt**.
3. Copy its entire line.
4. In Steam, right-click **Fallout: New Vegas → Properties → General**.
5. Paste into **Launch Options**, replacing the old TTWVR command.
6. Press **Play**. Fluorine starts the VR profile and game automatically.

Load a save and check the scene in both eyes while turning your head. In the mod's **VR Settings**, choose DLSS or FSR, quality level, resolution and sharpness.
