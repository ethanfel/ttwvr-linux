# Guide screenshots

Captured from the real native Fluorine Manager **0.4.1** UI on 2026-11-13, using the isolated test instance and a private Xvfb display. No game was launched for these captures. The test manager configuration was restored afterward.

- `fluorine-fuse.png`: region capture of **Settings → Compatibility → Advanced → Mod filesystem**.
- `fluorine-profiles.png`: profile dialog showing the separate flat/VR profiles and profile-local saves and INIs.

The images show actual controls, with no generated or substituted interface elements. Fluorine is by [SulfurNitride and contributors](https://github.com/SulfurNitride/Fluorine-Manager).
