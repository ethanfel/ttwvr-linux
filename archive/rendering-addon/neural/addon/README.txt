TTWVR Rendering Addon (GPL-3.0-only)
Source: https://github.com/ethanfel/ttwvr-linux/tree/main/archive/rendering-addon/neural

Requires the matching TTWVRNeuralRenderingLayer.dll and neural_host.exe,
registered in the private Proton prefix as described in neural/docs/STEAM.md.
Install this folder as a mod in Fluorine's VR profile. Disable the older TTWVR Neural
Menu mod. Open VR Settings; the addon controls follow Resolution.

AA choices: Off, DLAA, MSAA 2x/4x/8x. MSAA changes require restarting Fallout.
MSAA excludes NR/DLAA until a restart with MSAA off. NR and DLAA otherwise
apply live. NR tuning does not change the game's final eye resolution.

Verified TTWVR 1.1.0 and 1.1.3 builds are supported. No game, TTWVR or NVIDIA
binaries are included. See the source documentation for exact validation.
